# FraudShield AI

FraudShield AI is a multi-agent AI cybersecurity platform built for Hackathon 2026.

## Features
- AI-powered scam and phishing detection
- Autonomous agent workflow using n8n
- Real-time risk analysis
- Modern futuristic frontend
- Webhook-based AI architecture

## Tech Stack
- n8n
- Groq AI
- Loveable
- React
- Webhooks

## Architecture
Frontend → n8n Webhook → AI Workflow → JSON Response
